# 🛍️ Ecommerce Web App

Modern e-commerce frontend built with React + Tailwind CSS.

## 🚀 Features
- Product listing
- Clean and modern UI
- Responsive design
- Scalable project structure

## 🛠 Tech Stack
- React (Vite)
- Tailwind CSS
- React Router

## 📁 Project Structure
- components (UI parts)
- pages (routes)
- context (global state)
- services (API logic)

## ⚡ Getting Started

```bash
npm install
npm run dev
